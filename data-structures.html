Data Structures Library

Three abstract data type implementations in C++ built from scratch — no STL containers used. Each includes a custom iterator, full CRUD operations, exception handling, and an automated test suite.

C++ Data Structures Algorithms OOP Iterators Templates

Overview

Three independent data structure implementations, each with a clean interface, custom iterator, and automated tests covering edge cases and large inputs.

TAD 1

Dictionary

Hash table with open addressing (linear probing), dynamic resizing at 75% load factor, and lazy deletion via tombstone markers.

TAD 2

Ordered Dictionary

Singly linked list kept sorted by a user-supplied relation function. Supports ascending, descending, or any custom ordering.

TAD 3

Sparse Matrix

Dynamic array of sorted triplets (row, col, value) with binary search for O(log n) element access. Only non-zero values stored.

Dictionary — Hash Table

Open addressing with linear probing, dynamic resizing, and tombstone deletion.

Open Addressing

Collisions resolved with linear probing. Hash function: ((key % capacity) + capacity) % capacity to handle negative keys correctly.

Dynamic Resizing

When load factor exceeds 75%, the table doubles in size (capacity * 2 + 1) and all active elements are rehashed into the new array.

Tombstone Deletion

Deleted slots are marked with state -1 instead of being cleared, so probing chains remain intact. Empty slots are 0, active are 1.

Key Update

Adding an existing key replaces the value and returns the old one. Adding a new key returns NULL_TVALOARE.

Ordered Dictionary — Sorted Linked List

Singly linked list sorted by a relation function passed at construction time.

Custom Ordering

The relation Relatie r is a function pointer bool(*)(TCheie, TCheie) passed to the constructor — supports ascending, descending, or any total order.

Sorted Insertion

New nodes are inserted in the correct position by traversing until the relation fails, keeping the list always sorted.

Manual Memory Management

Nodes allocated with new, destructor walks the list and deletes each node. No memory leaks.

Iterator

Iterator walks the linked list in order, returning elements in the sorted sequence defined by the relation.


Sorted insertion — finds the correct position using the relation:

Sparse Matrix

Dynamic array of sorted triplets (row, col, value) — only non-zero elements stored.

Triplet Storage

Each non-zero element stored as struct Triplet { int linie, coloana; TElem valoare; }, sorted by row then column.

Binary Search

Element access uses binary search on the sorted triplet array — O(log n) per lookup instead of O(n) linear scan.

Dynamic Resizing

Underlying array doubles in capacity when full. Insertion maintains sorted order by shifting elements right.

Memory Efficient

A 300×300 matrix with sparse data uses only as much memory as there are non-zero elements — not 90,000 slots.


Binary search for element (i, j):

int Matrice::cautaIndex(int i, int j) const {
    int st = 0, dr = dimensiune - 1;
    while (st <= dr) {
        int mijloc = (st + dr) / 2;
        if (elems[mijloc].linie == i && elems[mijloc].coloana == j)
            return mijloc;
        if (elems[mijloc].linie < i || (elems[mijloc].linie == i && elems[mijloc].coloana < j))
            st = mijloc + 1;
        else
            dr = mijloc - 1;
    }
    return -1; // not found → element is 0
}

Complexity:

O(log n) element access
O(n) modify (shift on insert)
O(k) space (k = non-zero count)
O(1) nrLinii / nrColoane

Testing

Each TAD has a short test suite (basic operations) and an extended suite (edge cases, large inputs, stress tests).

Dictionary Tests

Create on empty, add 20,000+ elements with resize, delete odd/even keys, iterator on 60,000 elements, search after delete.

Ordered Dictionary Tests

Both ascending and descending relations. Random insertion order, iterator order verification after each delete, 6,000+ element stress test.

Sparse Matrix Tests

300×300 matrix with sparse pattern, element access, exception on invalid position, modify to zero (deletion), quantity test.
